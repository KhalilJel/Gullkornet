# Cidea Website Agents

The website engine uses specialized agents behind one orchestration layer.

## Orchestration order

Hermes is the top-level orchestrator. It delegates evidence collection and browser work instead of performing those tasks itself.

## Research agents

- Firecrawl: website extraction and structured page research.
- Agent Reach: external/public context and competitor intelligence.
- Agent Reach: external/public context and competitor intelligence.
- Browser Use: interactive UX and journey testing.

## Reasoning layers

- JEV Ultrafast: filter and prioritize raw research.
- Hermes: orchestrate agents and decide what needs deeper investigation.
- TypeSafe: validate machine-readable outputs.

## Specialist reviewers

- UX
- SEO
- CRO
- Design
- Content
- Performance
- Trust / authority

## Improvement loop

1. Gather evidence.
2. Validate and normalize.
3. Produce specialist findings.
4. Hermes prioritizes.
5. Generate an improvement plan.
6. Human approves.
7. Coding agent implements.
8. Re-audit.
9. Compare before/after scores.

No agent may invent evidence. Recommendations must reference collected evidence.
