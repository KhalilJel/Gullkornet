# Market Insight Pilot — Execution Checklist

## Stage 1: Scope the first sample
- [ ] Pick one niche with a clear business use case.
- [ ] Pick one geography.
- [ ] Define what a buyer would do with the dataset.
- [ ] Define inclusion and exclusion criteria.
- [ ] Confirm permitted sources, source terms, and practical request limits.

## Stage 2: Build a small dataset
- [ ] Discover 20–30 businesses using existing Gullkornet discovery tools.
- [ ] Normalize names and website domains.
- [ ] Deduplicate records.
- [ ] Record public source URLs and the date checked.
- [ ] Do not interpret missing data as proof that something does not exist.

## Stage 3: Verify and prioritize
- [ ] Manually verify a sample of records before making customer-facing claims.
- [ ] Separate observed facts from hypotheses.
- [ ] Use explicit review status and confidence.
- [ ] Remove unsupported or stale observations.
- [ ] Ensure each priority entry has a source URL.

## Stage 4: Produce deliverables
- [ ] Create a clean CSV/XLSX dataset.
- [ ] Create a concise report using MARKET-INSIGHT-REPORT-TEMPLATE.md.
- [ ] Explain scope, methodology, date checked, and limitations.
- [ ] Review the complete report before sharing.

## Stage 5: Validate willingness to pay
- [ ] Identify five potential buyers in the selected segment.
- [ ] Ask how they would use the report and what decisions it supports.
- [ ] Ask which fields are essential and what refresh cadence is useful.
- [ ] Test interest in a paid pilot and a recurring update.
- [ ] Record feedback before building more automation.

## Stage 6: Decide what to automate
- [ ] Automate only repeatable, validated steps.
- [ ] Keep customer datasets separate from Cidea's internal lead registry.
- [ ] Keep outbound sending out of scope for this pilot.
- [ ] Do not change DNS/MX or connect to SmartSvar production state.

## Decision gate

Proceed to recurring delivery only if at least one buyer demonstrates concrete intent to pay or a strong, specific use case. If not, revise the niche or deliverable before expanding the system.
