# Cidea Website Improvement Engine

Shared AI improvement system for CideaLead, CideaMarketing and CideaConsulting.

## Targets

- CideaLead: conversion, trust, lead generation and sales positioning.
- CideaMarketing: SEO, content, growth, social proof and marketing conversion.
- CideaConsulting: authority, consulting positioning, business problems, AI/digital transformation opportunities.

## Shared pipeline

Hermes -> Agent Reach / Firecrawl / Browser Use -> JEV Ultrafast -> TypeSafe -> specialist audits -> Improvement Director -> coding agent -> re-audit -> human approval -> deploy.

## Rules

1. Research once and reuse evidence across the three sites.
2. Firecrawl is the default website extraction layer.
3. Browser Use is an escalation path for interactive UX testing.
4. Agent Reach supplies external/public context.
5. JEV filters research before reasoning.
6. TypeSafe validates every machine-readable result.
7. No recommendation without evidence.
8. No automatic production deployment in the initial phase.
9. Never modify DNS or MX.
10. Keep the three sites strategically distinct even when sharing infrastructure.

## Initial audit dimensions

- UX
- SEO
- CRO
- Design
- Content
- Performance
- Trust / authority
- Business / offer clarity

## Output

Each site receives:
- score by dimension
- evidence-backed findings
- severity
- recommended improvements
- expected impact
- confidence
- top 5 prioritized changes

The system must optimize for measurable business improvement, not visual changes for their own sake.
